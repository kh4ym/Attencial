💡 Key Technical Learnings

  • 3-Tier Architecture: Separation of concerns with Shared DTOs enables code reuse and consistency across API and Client
  • JWT Authentication: Stateless auth with JWT tokens stored in localStorage enables scalable, secure authentication
  • Entity Framework Core: Code-first migrations make database versioning and teamwork much smoother
  • Blazor WASM: Full C# in the browser with WASM enables rich interactive experiences without JavaScript
  • CORS Configuration: Critical for browser security; must be explicitly configured for Blazor-to-API communication
  • JWT Claims: Custom claims in tokens (Email, Role) enable rich authorization logic
  • Password Security: BCrypt provides adaptive hashing with automatic salt handling
